## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/your-repository.git
   cd your-repository
   ```

2. Go to the folder of the project you want to run:

   ```bash
   cd javascript/project-name-1
   ```

3. Install dependencies (if the project has a `package.json`):

   ```bash
   npm install
   ```

4. Run the project:

   ```bash
   # JavaScript
   node index.js

   # TypeScript (using ts-node)
   npx ts-node index.ts
   ```

Each project's own README has any extra instructions.
